# arXiv submission

Upload `manuscript_arxiv.pdf` (40 pages, fonts embedded, no line numbers). arXiv accepts a PDF-only upload for papers not written in LaTeX.

## Before you start

- [ ] **All five co-authors agree** to posting a public preprint. An arXiv posting can't be deleted, only withdrawn, and the withdrawn version stays visible.
- [ ] Create an account at https://arxiv.org/user/register, using your institutional email if you can. A university email makes endorsement easier.
- [ ] **Endorsement:** first-time submitters to a category may need an endorser. arXiv shows this during submission. Ask someone who has already published in `stat.AP`, such as a co-author or supervisor, to endorse you using the code arXiv gives you.

## Notes

- The ethics section is unchanged: it honestly says no ethics committee reviewed the study. arXiv moderators may put the paper on hold or ask questions about the human-subjects data. If that happens, answer truthfully that the data are de-identified, retrospective and used with the custodian's permission.
- The additional files can't be attached to a PDF-only arXiv submission. The manuscript points to the GitHub repository for code and materials.
- A preprint does not stop you submitting to BMC Public Health later. BMC allows preprints; mention the arXiv ID in the cover letter when you do.
